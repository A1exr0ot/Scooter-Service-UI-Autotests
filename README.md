## 🎯 О проекте

Учебный проект, демонстрирующий построение фреймворка автоматизации UI-тестирования на Java с использованием Selenium WebDriver. Покрывает ключевые пользовательские сценарии сервиса аренды самокатов.

**Цели проекта:**

- Отработка паттернов **Page Object** и **Steps**
- Кросс-браузерный запуск тестов (**Chrome**, **Firefox**)
- Работа с явными ожиданиями `WebDriverWait`
- Управление драйверами через `WebDriverManager`

## 🧪 Тестовые сценарии

### 1️⃣ Блок «Вопросы о важном» — `FaqTest`

Проверяет, что при клике на вопрос раскрывается соответствующий ответ.

**Проверяемые вопросы (8 шт.):**

1. Сколько это стоит? И как оплатить?
2. Хочу сразу несколько самокатов! Так можно?
3. Как рассчитывается время аренды?
4. Можно ли заказать самокат прямо на сегодня?
5. Можно ли продлить заказ или вернуть самокат раньше?
6. Вы привозите зарядку вместе с самокатом?
7. Можно ли отменить заказ?
8. Я живу за МКАДом, привезёте?

**Шаги:**

1. Открыть главную страницу
2. Проверить видимость вопроса
3. Кликнуть по вопросу
4. Считать текст ответа
5. Сравнить с ожидаемым

**Запускается в:** `Chrome`, `Firefox`

---

### 2️⃣ Оформление заказа — `OrderMakeTest`

Позитивный сценарий оформления заказа с двумя наборами данных и двумя точками входа.

**Точки входа:**

- 🔼 Кнопка «Заказать» в шапке страницы
- 🔽 Кнопка «Заказать» внизу страницы

**Шаги:**

1. Открыть главную страницу
2. Нажать одну из кнопок «Заказать»
3. Заполнить форму **«Для кого самокат»**: имя, фамилия, адрес, метро, телефон
4. Нажать «Далее»
5. Заполнить форму **«Про аренду»**: дата, срок аренды, цвет самоката
6. Нажать «Заказать»
7. Подтвердить действие в модальном окне «Да»
8. Проверить появление окна «Заказ оформлен»

**Запускается в:** `Chrome`, `Firefox`

---

### 3️⃣ Логотип «Самокат» — `LogoSamokatTest`

Проверяет, что клик по логотипу возвращает на главную страницу сервиса.

**Шаги:**

1. Открыть главную страницу
2. Кликнуть по логотипу «Самокат»
3. Проверить, что текущий URL совпадает с `MainPage.URL`

**Запускается в:** `Chrome`, `Firefox`

---

### 4️⃣ Логотип «Яндекс» — `LogoYandexTest`

Проверяет, что клик по логотипу Яндекса открывает главную страницу Яндекса в новой вкладке.

**Шаги:**

1. Открыть главную страницу
2. Кликнуть по логотипу «Яндекс»
3. Дождаться открытия второй вкладки
4. Переключиться на неё
5. Сравнить URL с ожидаемым (`https://yandex.ru/`)

**Запускается в:** `Chrome`, `Firefox`

## ▶️ Запуск тестов

### 🚀 Все тесты

```bash
mvn clean test
```

### 🎯 Конкретный тестовый класс

```bash
mvn -Dtest=FaqTest test
mvn -Dtest=OrderMakeTest test
mvn -Dtest=LogoSamokatTest test
mvn -Dtest=LogoYandexTest test
```

### 🔍 Один тестовый метод

```bash
mvn -Dtest=OrderMakeTest#successfulOrderUp test
```

**Отчёты** Maven Surefire генерируются в каталоге:

```
target/surefire-reports/
```

## 💡 Особенности реализации

| ✨ Особенность | 📝 Описание |
|:---|:---|
| **Кросс-браузерность** | JUnit `@Parameterized` — каждый тест прогоняется в Chrome и Firefox |
| **WebDriverManager** | Автоматическая установка драйверов |
| **Page Object + Steps** | Чистота тестов и переиспользуемость кода |
| **Явные ожидания** | `WebDriverWait` для динамических элементов |
| **JS-скроллинг** | `scrollIntoView` для стабильных кликов по нижним элементам |
